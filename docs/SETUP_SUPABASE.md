# Guía de Configuración y Conexión a Supabase - PréstamoLab

Esta guía explica cómo configurar la conexión a **Supabase** tras clonar este repositorio en una nueva máquina de desarrollo.

---

## 1. Configuración de Credenciales Locales (`local.properties`)

Dado que el archivo `local.properties` está excluido en `.gitignore` por seguridad, **debes crearlo manualmente** en la raíz del proyecto tras clonar el repositorio.

1. Abre la raíz del proyecto en Android Studio.
2. Crea (o abre) el archivo `local.properties`.
3. Agrega la ruta de tu SDK de Android y tus credenciales de Supabase:

```properties
sdk.dir=C\:\\Users\\TuUsuario\\AppData\\Local\\Android\\Sdk
SUPABASE_URL=https://ejemplo.supabase.co/
SUPABASE_ANON_KEY=sb_publishable_ejemplo
```

> **Nota:** Sustituye `sdk.dir` por la ruta correspondiente a tu sistema operativo o deja que Android Studio la genere automáticamente.

4. Sincroniza o recompila el proyecto (`Build > Rebuild Project`). Gradle inyectará estas variables automáticamente en la clase compilada `BuildConfig`.

---

## 2. Configuración en la Consola de Supabase (Opcional si usas tu propio proyecto)

Si deseas conectar la app a tu propio proyecto de Supabase desde cero:

### A. Estructura de Tablas (SQL Editor)
Ejecuta la siguiente consulta en el **SQL Editor** de Supabase:

```sql
-- 1. Tabla de Equipos
CREATE TABLE equipos (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre TEXT NOT NULL,
    categoria TEXT NOT NULL,
    estado TEXT NOT NULL DEFAULT 'DISPONIBLE',
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Insertar equipos iniciales
INSERT INTO equipos (nombre, categoria, estado) VALUES
('Multímetro Digital', 'ELECTRONICA', 'DISPONIBLE'),
('Kit de Arduino', 'ELECTRONICA', 'DISPONIBLE'),
('Cámara Digital', 'AUDIOVISUAL', 'DISPONIBLE'),
('Portátil Lenovo', 'COMPUTO', 'DISPONIBLE'),
('Taladro Inalámbrico', 'HERRAMIENTAS', 'DISPONIBLE');

-- 2. Tabla de Solicitudes
CREATE TABLE solicitudes (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    equipo_id BIGINT REFERENCES equipos(id) ON DELETE CASCADE,
    ambiente_destino TEXT NOT NULL,
    proposito TEXT NOT NULL,
    duracion_horas INT NOT NULL,
    estado TEXT NOT NULL DEFAULT 'SOLICITADA',
    fecha_solicitud BIGINT NOT NULL,
    latitud DOUBLE PRECISION,
    longitud DOUBLE PRECISION,
    foto_uri TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### B. Políticas de Seguridad RLS (SQL Editor)

```sql
ALTER TABLE equipos ENABLE ROW LEVEL SECURITY;
ALTER TABLE solicitudes ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Permitir lectura publica en equipos" ON equipos FOR SELECT TO anon, authenticated USING (true);
CREATE POLICY "Permitir insercion publica en equipos" ON equipos FOR INSERT TO anon, authenticated WITH CHECK (true);
CREATE POLICY "Permitir actualizacion publica en equipos" ON equipos FOR UPDATE TO anon, authenticated USING (true) WITH CHECK (true);
CREATE POLICY "Permitir eliminacion publica en equipos" ON equipos FOR DELETE TO anon, authenticated USING (true);

CREATE POLICY "Permitir lectura publica en solicitudes" ON solicitudes FOR SELECT TO anon, authenticated USING (true);
CREATE POLICY "Permitir insercion publica en solicitudes" ON solicitudes FOR INSERT TO anon, authenticated WITH CHECK (true);
CREATE POLICY "Permitir actualizacion publica en solicitudes" ON solicitudes FOR UPDATE TO anon, authenticated USING (true) WITH CHECK (true);
CREATE POLICY "Permitir eliminacion publica en solicitudes" ON solicitudes FOR DELETE TO anon, authenticated USING (true);
```

### C. Almacenamiento de Fotos (Storage Bucket)
1. Ve a **Storage** en Supabase > **New Bucket**.
2. Asigna el nombre `evidencias`.
3. Marca la casilla **Public Bucket**.
4. Aplica las políticas RLS correspondientes para lectura y subida libre en `storage.objects`.
