# [HU-12] Gestionar inventario de equipos (instructor)

**Etiquetas:** `historia-usuario`, `prioridad:media`, `sprint-6`  
**Prioridad:** Media · **Sprint:** 6

## Historia de usuario

**Como** instructor, **quiero** registrar y mantener el inventario de equipos, **para** que el catálogo refleje los recursos reales del CTMA.

## Criterios de aceptación

- [ ] **CA-HU12-01:** **Dado** que soy INSTRUCTOR, **cuando** registro un equipo con nombre y categoría, **entonces** se guarda con estado DISPONIBLE y aparece en el catálogo.
- [ ] **CA-HU12-02:** **Dado** que estoy registrando un equipo, **cuando** dejo vacío el nombre o la categoría, **entonces** veo el error del campo y no se guarda.
- [ ] **CA-HU12-03:** **Dado** que existe un equipo, **cuando** edito sus datos, **entonces** los cambios se ven en el catálogo y en el detalle.
- [ ] **CA-HU12-04:** **Dado** que el equipo tiene un préstamo activo (SOLICITADA o PRESTADO), **cuando** intento eliminarlo, **entonces** la eliminación se rechaza con un mensaje explicativo.
- [ ] **CA-HU12-05:** **Dado** que soy ESTUDIANTE, **cuando** abro el catálogo, **entonces** no veo opciones para crear, editar ni eliminar equipos.
