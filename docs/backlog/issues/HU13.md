# [HU-13] Registrar geolocalización de las operaciones

**Etiquetas:** `historia-usuario`, `prioridad:media`, `sprint-7`  
**Prioridad:** Media · **Sprint:** 7

## Historia de usuario

**Como** instructor, **quiero** saber dónde se solicitó, devolvió o fotografió cada equipo, **para** verificar que las operaciones ocurren dentro del CTMA.

## Criterios de aceptación

- [ ] **CA-HU13-01:** **Dado** que no he concedido permisos de ubicación, **cuando** solicito un préstamo, **entonces** la app pide primero ubicación aproximada (COARSE) y solo pide la precisa (FINE) en esa acción.
- [ ] **CA-HU13-02:** **Dado** que concedí el permiso de ubicación, **cuando** solicito un préstamo, **entonces** la solicitud guarda latitud, longitud y precisión.
- [ ] **CA-HU13-03:** **Dado** que concedí el permiso de ubicación, **cuando** registro una devolución o adjunto una evidencia, **entonces** el registro guarda latitud y longitud de ese momento.
- [ ] **CA-HU13-04:** **Dado** que negué el permiso o el GPS está desactivado, **cuando** solicito o devuelvo, **entonces** la operación se completa sin coordenadas, marcada "sin ubicación", y se muestra un aviso.
- [ ] **CA-HU13-05:** **Dado** que hay registros con coordenadas, **cuando** se sincroniza, **entonces** latitud y longitud llegan a Supabase en el registro correspondiente.
